# Werning fouls/90 vs multi-source design

Date: 2026-07-25

## What Werning did

Tournament-wide **called fouls per scheduled minute**, Poisson rate test ARG vs
ESP, p ≈ 0.45. Pairwise matrix across 48 teams. Conclusion rhetoric: “dirty”
claim not consistent with data.

## Why that estimand is wrong for the public claim

1. Called fouls = ref decisions, not committed fouls.
2. “Dirty” in discourse = intensity, tactical counters, recaditos, **cards
   not shown**, non-calls.
3. Failure to reject equal rates ≠ equivalence; power is low.
4. Style/possession confounds volume.

## Our split estimands

| ID | Question | Data |
|----|----------|------|
| A | Do official foul rates differ (ARG vs peers)? | Opta totals / ESPN boxscores |
| B | Do independent writers agree on under-carding / uncalled actions? | Liveblogs + reports, multi-language |
| C | (Later) Video-coded intensity for multi-agreed incidents | Broadcast |

A can be true “no volume difference” while B is true “under-carded spoiling.”

## Pilot result (final only, Anglophone)

- F01 Mac Allister–Olmo under-carded: **5/5 English sources + ex-ref**.
- F05 spoiling/leniency narrative: **4/5**.
- F06 Spain under-carded control: **0/5** English hits despite 21 fouls / 0 cards.
- Spanish/Argentine columns not yet coded → no “global” claim yet.
